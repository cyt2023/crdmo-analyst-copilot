# AI Usage Disclosure

## Suggested Submission Statement

This coursework project used generative AI tools to support software prototyping, workflow design, prompt drafting, interface copywriting, and document structuring.

The AI assistance was used to help:

- scaffold the repository and application files
- draft a Streamlit prototype
- structure prompt templates for multiple analytical agent roles
- draft workflow documentation for a Coze / XIPU-AI implementation
- prepare a sample report format and user documentation

Human team members remained responsible for:

- defining the project scope and product concept
- selecting the target industry and case company
- reviewing all financial logic and formulas
- checking the appropriateness of CRDMO industry terminology
- validating the distinction between sample data and verified data
- editing the final written submission and presentation
- deciding the final assumptions, interpretations, and conclusions

## Data And Accuracy Disclosure

The bundled financial figures in this repository are clearly labelled sample prototype data for demonstration only. They are not claimed to be audited, verified, or suitable for investment use. Final coursework submission should replace sample values with verified information from primary company disclosures or trusted databases if required by the course.

## Academic Integrity Position

The final submitted work should reflect the group’s own understanding, review, and judgement. AI-generated content should be treated as a drafting and structuring aid, not as an unquestioned authority. All group members should understand the model logic, prompt design, limitations, and conclusions well enough to explain them independently during presentation or assessment.
